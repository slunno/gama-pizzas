# 🍕 Gama Pizzas

![Gama Pizzas](src/assets/images/logo.png)

## 📌 Sobre o Projeto

O **Gama Pizzas** é um site institucional desenvolvido para apresentar os serviços de **rodízio de pizzas para eventos**, oferecendo uma experiência moderna, elegante e intuitiva para divulgação da marca.

O objetivo principal do projeto é facilitar o contato com clientes, apresentar os serviços oferecidos e transformar visitantes em potenciais clientes através de uma interface visual atrativa.

O site apresenta:

* História da empresa
* Cardápios de rodízio
* Sabores disponíveis
* Galeria de eventos
* Informações de contato
* Integração com WhatsApp
* Apresentação dos diferenciais da marca

# ⚙️ Instalação do Projeto

## 1. Clonar o repositório

```bash
git clone https://github.com/seuusuario/gama-pizzas.git
```

## 2. Acessar a pasta do projeto

```bash
cd gama-pizzas
```

## 3. Instalar dependências

```bash
npm install
```

## 4. Executar ambiente de desenvolvimento

```bash
npm run dev
```

O projeto estará disponível em:

```
http://localhost:5173
```

# 🔐 Segurança

Atualmente o projeto funciona como uma aplicação exclusivamente frontend.

Não possui:

* Banco de dados
* Sistema de autenticação
* API privada
* Armazenamento de dados sensíveis

Medidas aplicadas:

* Uso de HTTPS em produção
* Controle de dependências
* Código modularizado
* Organização de componentes
* Evitar exposição de informações sensíveis
